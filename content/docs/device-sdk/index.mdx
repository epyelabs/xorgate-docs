This section documents the software running on xorgate hardware: installing and
provisioning the agent, the MQTT cloud contract it speaks (telemetry, status,
retained configuration and its reported counterpart, and the command topic), the
`xorgate` CLI, the configuration reference, and the GStreamer pipelines that feed
live video. It also states the current extension limits plainly, since the
collector set, the topic layout and the command set are all closed today.

Unlike the other two SDK sections, the Device SDK is documentation of software
that already exists rather than a design for a new library.
