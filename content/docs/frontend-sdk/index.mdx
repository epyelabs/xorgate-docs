This section documents the React SDK: a provider that carries configuration and
credentials, plus headless hooks for devices, live telemetry over MQTT, telemetry
history, the KVS WebRTC live viewer, and the recorded-media replay player. It
brings no styling opinion, so the chrome stays yours.
