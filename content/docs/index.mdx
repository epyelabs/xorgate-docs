Xorgate is an end-to-end platform for **Physical AI and Edge IoT**: the connective
layer between rugged sensing hardware in the field and intelligent cloud
workflows. It ships hardware kits, a device agent, cellular-first video and
telemetry pipelines, a REST API, and SDKs for the edge, the cloud, and the
client.

These docs are for engineers integrating with xorgate: reading devices and their
telemetry, embedding live or recorded video, and provisioning hardware from your
own product.

## Status of these docs

The site is being written alongside the SDKs it describes, so sections land at
different times. Pages that describe something not yet shipped say so plainly
rather than implying it exists. In particular:

- The **API reference** is generated from the core service's OpenAPI document,
  which does not yet cover every route.
- The **Backend SDK** and **Frontend SDK** sections are design documents first.
  The packages follow the docs, not the other way around.
- The **Workflows** section documents the definition format, the node catalog
  and the engine, all of which are stable and runnable, and states the plan
  for the platform to run on that same engine. The platform's workflow API
  (templates, attachments, runs) is still not in the reference.
- API-key authentication **works**: a minted `xg_` key authenticates the REST
  surface at its own role, and can vend credentials for the live plane on
  behalf of one workspace. See
  [Authentication](/getting-started/authentication).
