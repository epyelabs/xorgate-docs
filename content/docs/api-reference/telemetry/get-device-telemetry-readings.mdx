      - content: >-
          Raw (un-averaged) stored samples for one page, paginated over DISTINCT
          timestamps so a page boundary never splits a sample. Defaults to the
          latest samples (`order=desc`) with no time window. `limit`/`offset`
          count timestamps (samples), not rows, and unlike the other list
          endpoints an out-of-range `limit` is a 400 rather than being clamped.


          **Two response shapes, selected by `shape`.** `shape=table` (the
          DEFAULT) returns the table being displayed: an ordered `columns` list
          with stable units, and one `rows` entry per timestamp whose `v` array
          is positional against `columns`. `shape=flat` returns the original
          `readings: [{ts, metric, value, unit}]` rows, the same raw-rows
          contract as `/telemetry` and `/telemetry/recent`. The table shape is
          roughly 10x smaller on the wire (this API does not compress) and its
          column set does not vary with the page contents.


          `page.total` is the distinct-timestamp count, **bounded at 10,000**:
          when more samples match, `page.totalIsCapped` is `true` and only the
          first 10,000 in the requested `order` are addressable (newest first by
          default). `page.coveredFrom`/`coveredTo` give the ISO span of that
          addressable slice. Narrow `from`/`to` to reach beyond it; an `offset`
          past the cap returns an empty page, not an error.
