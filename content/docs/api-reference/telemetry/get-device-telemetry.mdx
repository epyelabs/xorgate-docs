          Stored readings for the device over `[from, to)`, ordered by `ts` then
          `metric`. Both bounds are REQUIRED and the range may not exceed 31
          days.


          With `interval` (seconds) the result is downsampled server-side:
          readings are grouped into `interval`-wide buckets per metric and
          averaged, up to 10,000 buckets. Without it, raw rows are returned up
          to 5,000. Either way `truncated: true` means the cap was hit and the
          result is incomplete, so narrow the range or pass a coarser
          `interval`. This endpoint does not paginate; `truncated` is the only
          signal that data was left behind.
