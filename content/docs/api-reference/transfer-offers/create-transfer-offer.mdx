          Mints a code that another organization can redeem to take ownership of
          this device.


          Use this when you do NOT share a membership with the destination — a
          genuine handover to a customer. If you personally hold `owner` or
          `admin` in both organizations, `POST /devices/{id}/transfer` with an
          `organizationId` does the same move in one call.


          **The code is a bearer token.** Anyone holding it can read the offer's
          preview and accept or decline it. Send it over a channel you trust. It
          expires after 7 days.


          **Idempotent.** A device has at most one open offer. Calling this
          again while one is pending returns the existing offer with **200**
          instead of minting a second claimable code; a genuinely new offer
          returns **201**.


          `willDetachWorkflowAttachments` names the workflow templates this
          device is attached to. If the offer is accepted by a different
          organization they are all detached, because they belong to yours and
          the new owner cannot see them. It is returned HERE, at creation,
          because you are not present when the offer is accepted — this is the
          last point at which you can reconsider.
