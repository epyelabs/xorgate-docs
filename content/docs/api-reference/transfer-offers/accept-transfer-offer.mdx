          Moves the device into one of YOUR workspaces and runs the full
          transfer, including the cross-organization sweep. Requires `owner` or
          `admin` in the accepting organization.


          Everything in `POST /devices/{id}/transfer` applies from here on: all
          historical telemetry and all recorded footage come with the device,
          the device does not have to be online, and `transfer.adoption` says
          whether it has confirmed the change yet.


          Accepting is race-safe: the offer is claimed with a conditional write
          before the transfer runs, so only one of two simultaneous accepts
          wins. If the transfer itself fails the offer is put back to `pending`
          and the code can be retried.
