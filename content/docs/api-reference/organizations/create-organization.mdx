          row with `role: owner`. Does NOT require `X-Organization-Id` (the
          caller may have no orgs yet), which makes it the one write a brand-new
          user can perform.


          **Cognito ID token only** (`401 USER_CREDENTIAL_REQUIRED` for an API
          key). The new organization needs an owner, and an owner is a user.
          This is a known limit for a consumer that wants to onboard its own
          customers programmatically: today it maps them onto WORKSPACES inside
          its one organization, which a default `member` key can create.
          Organizations for a consumer are provisioned out of band.
