      - content: >-
          AWS IoT does not authorize MQTT for Cognito-federated principals
          through their IAM role. It requires an IoT policy attached to the
          Cognito IDENTITY. This endpoint resolves the caller's identity from
          the bearer token and attaches the browser policy to it, after which
          the browser can connect over MQTT-over-WSS and subscribe to
          `xorgate/devices/{deviceId}/telemetry`. Idempotent, so calling it on
          every page load is fine.


          Note the current policy is org-blind: it authorizes the telemetry
          topic space broadly rather than per organization, so it is safe for
          first-party use and NOT yet safe to hand to a third party. Narrowing
          it is tracked as platform-readiness work.
