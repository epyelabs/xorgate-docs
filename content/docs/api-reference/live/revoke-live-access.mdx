      - content: >-
          The counterpart to `POST /live/access`: withdraws the authorization
          from the Cognito identity behind your bearer token, after which the
          broker refuses that identity's next connection and any live
          subscription dies on its next reconnect. Idempotent — revoking access
          you do not have returns the same 200.


          Self-service only. Revoking someone else's live access is a
          consequence of removing their membership: `DELETE /memberships/{id}`
          revokes automatically when the removal takes away their LAST
          organization membership. It deliberately does not fire while the user
          still belongs to another organization, because the grant is one shared
          org-blind authorization and they remain entitled to it.


          Unlike the grant, this needs only a valid token and no organization
          membership: someone who has just lost their last membership must still
          be able to clean up after themselves.


          **Cognito ID token only**, for the same reason as the grant: there is
          no Cognito identity behind an API key to revoke (`401
          USER_CREDENTIAL_REQUIRED`).
