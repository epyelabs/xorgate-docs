      - content: >-
          Asks the device to read the text messages its cellular modem holds
          (SIM and modem storage) and return the newest `limit`. Reading is
          non-destructive: nothing is deleted and unread messages stay unread.
          Returns `202` with a `pending` read; poll `GET
          /devices/{id}/sms-reads/{readId}` (every second or two) until `status`
          is no longer `pending`. A read takes a few seconds and expires after
          45 s.


          Xorgate keeps only the device's latest successful read (served by `GET
          /devices/{id}/sms-reads/latest`, also while the device is offline);
          each new successful read replaces it. Any member of the organization
          may read, viewers included.
