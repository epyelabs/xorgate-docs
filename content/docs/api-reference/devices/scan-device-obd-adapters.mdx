          writes it with `PATCH /devices/{id}/config {"obd": {"adapterMac":
          "..."}}`. Only for a device whose model declares `peripherals.obd`
          (`400` `NOT_OBD_DEVICE` otherwise). Rate-limited server-side to one
          scan per device per 60 s (`429` `RATE_LIMITED`,
          `details.retryAfterMs`), because discovery stalls the helper''s
          polling while it runs. Ordinary member access, since nothing on the
          device changes. The device must be online (409 otherwise).'
