          It exists so a confirmation can NAME the consequences before the
          operator agrees rather than report them afterwards — in particular the
          workflow attachments a cross-organization move will detach, which
          cannot be reconsidered once the transfer has run.


          Refusals come back in `blockers` rather than as an error status, so
          the reason can be shown in place. `POST` turns the first blocker into
          its own 400 or 409.
