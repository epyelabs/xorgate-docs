      - content: 'Publishes a one-shot update command over MQTT. The device starts a
          systemd one-shot that downloads the latest published build (see GET
          /device-dist/latest), installs it, and restarts the agent, so the
          device drops offline for roughly a minute or two. Latest-only: there
          is no version parameter. A failed install rolls back, leaving the
          device on its current build. IMPORTANT: 202 means the command reached
          the broker, NOT that the update succeeded, and the ack could not tell
          you either (the agent is restarted mid-update). Observe the outcome by
          polling GET /devices/{id} until `agentVersion` changes; an unchanged
          build after the device returns online means the update failed and
          rolled back (diagnose on the device with `journalctl -u
          xorgate-updater`). The device must be online (409 otherwise). Pressing
          this twice is harmless: `systemctl start` on an already-running
          one-shot coalesces into the run in flight.'
