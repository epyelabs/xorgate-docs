          namespace) or `{"obd": {"adapterMac": null, ...}}`, otherwise the
          retained config re-pairs the same adapter on the device''s next
          settings poll. Reversible (set an adapter again), so it takes the
          ordinary write gate (owner/admin/member). Only for a device whose
          model declares `peripherals.obd` (`400` `NOT_OBD_DEVICE` otherwise).
          The device must be online (409 otherwise).'
