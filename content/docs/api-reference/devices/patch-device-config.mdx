          `configRev`, and publishes the whole document as a retained MQTT
          message on `xorgate/devices/{id}/config`. Each present namespace is
          validated and replaced WHOLE, because the device replaces namespaces
          the same way and a partial namespace would silently drop the keys it
          omits. `null` reverts a namespace to device defaults. Two namespaces
          are gated on the device: `simulation` is accepted only for a simulated
          device and `obd` only for a device whose model declares
          `peripherals.obd` (400 otherwise, naming the namespace). Returns 502
          when the row was written but the retained publish failed: the device
          has NOT been told yet, though it self-heals on its next config
          report.'
