      - content: >-
          Asks the device to delete every text message its cellular modem holds
          (SIM and modem storage), then read the stores again. A full store
          makes the modem refuse new messages; this empties it. **Destructive
          and irreversible**, so only owners and admins may clear (members and
          viewers get `403` `INSUFFICIENT_ROLE`).


          Returns `202` with a `pending` `SmsRead` whose `action` is `clear`;
          poll `GET /devices/{id}/sms-reads/{readId}` exactly as for a read. On
          `ok`, `result` is the device's state after the delete (normally no
          messages, with fresh storage counts) plus `cleared`, how many messages
          each store held before. A successful clear replaces the stored copy,
          so `GET /devices/{id}/sms-reads/latest` serves it until the next read
          and the previously stored message text is gone from Xorgate too.
          `limit` sizes that follow-up read, with the same rules as a read.
