      - content: Publishes a one-shot reboot command over MQTT and returns immediately.
          202 means the command was delivered to the broker, not that the device
          has rebooted; observe the outcome via the device status, which goes
          offline and then back online. The device must be online (409
          otherwise), because commands are not retained and there is nothing for
          an offline device to pick up later. The command expires 60 seconds
          after issue and carries a request id the device refuses to execute
          twice, so a stale or redelivered command cannot cause a surprise
          reboot.
