          Paginated with the shared list dialect, and filterable by `status` and
          by `tag`.


          `tag` is what makes this endpoint useful to a program: tag the
          templates your integration owns, then find them by that tag rather
          than by name or id. Repeating the parameter and comma-separating its
          values are the same request, and the semantics are ANY-of:
          `?tag=geofence&tag=speeding` returns templates carrying EITHER. There
          is no ALL-of mode.


          Rows carry the metadata and the tags, not the graph. Read one template
          to get its versions and their definitions.
