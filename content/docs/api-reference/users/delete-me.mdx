      - content: >-
          Closes the account for good: the Cognito user (so the email can sign
          up again from nothing), the profile row and picture, every
          organization membership, and the browser live-plane policy.
          Organizations the caller merely belonged to are untouched; device
          registrations they created keep a null creator.


          Refused with `409 OWNS_ORGANIZATIONS` while the caller is the ONLY
          owner of any organization — the response lists them under
          `details.organizations`. Hand ownership to another member first
          (`PATCH /memberships/{id}` with `role: "owner"`) or delete the
          organization (`DELETE /organizations/{id}`). Several owners are
          allowed, so an owner who is not the last one is not blocked.


          The ID token that made this call stays verifiable until it expires,
          but every later request with it is refused with `401 ACCOUNT_DELETED`
          rather than re-creating the profile. There is no undo.


          **Cognito ID token only.** An `xg_` API key is refused with `401
          USER_CREDENTIAL_REQUIRED`: this operation acts on a person, and a key
          has no user behind it.
