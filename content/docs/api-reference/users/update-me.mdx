          and clients fall back to the email address. Nothing else about a user
          is editable here: the email is the Cognito sign-in and the tier and
          platform role are not self-service.


          The name is NOT written back to the Cognito `name` attribute. That
          attribute seeds the row the first time a token is seen and has no
          reader afterwards; this row is the profile.


          **Cognito ID token only.** An `xg_` API key is refused with `401
          USER_CREDENTIAL_REQUIRED`: this operation acts on a person, and a key
          has no user behind it.
