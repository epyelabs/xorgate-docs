          SHA-256 is stored, so a lost key cannot be recovered, only replaced.
          Send the result as `Authorization: Bearer xg_...` to any
          organization-scoped operation in this document.


          A key may not be minted more privileged than the caller minting it: an
          `admin` cannot mint an `owner` key (`403`), because that would be a
          one-step escalation to deleting the organization.
